Построение эталона НСИ и классификация должностей

Проект предназначен для очистки, нормализации и построения эталонного справочника должностей на основе «сырых» данных. Включает автоматическую обработку с помощью LLM (Ollama), ручную валидацию, кластеризацию и классификацию новых записей.

1. Клонирование репозитория
    bash
    git clone https://github.com/Eretik1/nsis-job-classifier.git
    cd nsis-job-classifier

2. Создание виртуального окружения
    bash
    python -m venv venv
    venv\Scripts\activate     # Windows

3. Установка зависимостей
    bash
    pip install -r requirements.txt

Шаг 1. Ручная обработка (пополнение словарей)
    bash
    python src/manual_processor.py
    Этот скрипт загружает данные из .csv файлов папки data, извлекает все слова с точкой и предлагает в интерактивном режиме расшифровать сокращения или удалить стоп‑фразы. Результаты сохраняются в БД.

Шаг 2. нормализация

    LLM‑нормализация
    bash
    python src/llm_processor.py
    Скрипт обрабатывает каждую должность через Ollama, применяет очистку и лемматизацию. Обработанные записи сохраняются в job_titles. Поддерживается возобновление после прерывания.

    Алгоритмическия нормализация
    bash
    python src/processor.py
    Скрипт выполняет многоступенчатую очистку должностей: удаление лишних символов, расшифровку сокращений из словаря, удаление стоп‑фраз и лемматизацию. Обработанные записи сохраняются в job_titles.

Шаг 3. Ручное редоктирование записей
    bash
    python src/monual_editing.py
    Поочерёдно просматривает записи в job_titles и позволяет их редактировать.

Шаг 4. Построение эталонного справочника
    bash
    python src/build_reference.py
    На основе нормализованных названий выполняется кластеризация (TF‑IDF + иерархическая кластеризация), выбираются эталонные названия и сохраняются в reference_titles. Затем всем записям job_titles проставляется reference_id.

Шаг 5. Классификация пользовательской должности
    bash
    python src/classify_job.py "зам. гл. бухгалтера"

    или в интерактивном режиме:

    bash
    python src/classify_job.py

Шаг 6. Визуализация кластеров
    bash
    python src/visualize_clusters.py
    Создаёт t‑SNE проекцию и дендрограмму для оценки качества кластеризации.
